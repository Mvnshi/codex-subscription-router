Made for your Mac.

Apple silicon

Install the ChatGPT app and open it once. Then press Command + Space, type Terminal, press Enter, paste the line below, and press Enter. It builds your local copy and opens it.

curl -fsSL https://raw.githubusercontent.com/Mvnshi/codex-subscription-router/main/install.sh | /bin/bash

What to expect

  • If developer tools are missing it offers to install them (Apple’s own installer, and Homebrew for Go and Node.js)
  • No Apple developer certificate? It offers a basic signature: accounts, routing and usage work; Computer Use and Appshots may not
  • It asks before building from a ChatGPT build the project hasn’t recorded
  • Next time: Command + Space, then “Codex Subscription Router”

Questions, answered

A few things
to know.

More detail lives in the documentation.

Is Router actually free?+

Yes. The router is free and open source under the MIT license. It does not include a ChatGPT subscription; you connect plans you already have.

Does it give me unlimited usage?+

No. Each subscription keeps its own limits. Router helps use available quota across your connected accounts. When all accounts are depleted, it shows a combined limit alert.

Will it use my reset credits automatically?+

By default, no. “Ask me” requires confirmation before you spend a reset. You can opt into “Use automatically” from the account menu; ordinary account failover comes first. Credits belong to their account and are never transferred.

Is this an official OpenAI app?+

No. This is an independent community project, unaffiliated with OpenAI. It builds a separate, locally patched desktop app from your existing official installation. Review the source and the terms governing your subscriptions.

What happens when the official app updates?+

The router is a separate copy, so it keeps working until you rebuild it; run the same install line again and it keeps your accounts. The official app changes about every day, so the project checks itself daily: a test installs the newest build on clean machines and tracks it in a public issue. A build nobody has recorded yet is not refused. The installer says so and asks, and the patch stops by itself if the app changed in a way it doesn’t cover.

Does it work on Windows?+

Yes. It works with the Microsoft Store build of the Codex app. Routing and failover were checked live on two real subscriptions, and the daily test installs, patches and starts the newest build on x64 and on real ARM64 Windows. It stays labelled provisional: a real reset redemption, a Computer Use turn and routing on ARM64 haven’t been exercised yet. Any change the patch doesn’t recognise stops the install rather than guessing.

Which one do I open, Codex Router or the normal Codex app?+

Open Codex Router (Start menu or Desktop; its icon is a dark tile with a route that splits in two). The normal Codex app keeps working, but it only knows your first account, so a chat sent from it can hit that account’s limit while another subscription still has usage. Both list the same chats, so an old error message may show in the router even though it happened in the other app.

How do I remove it?+

On Windows run the uninstall script from the repository (it can preview with -WhatIf and only deletes your accounts if you ask); on a Mac move the two router apps to the Trash. The official app is never changed, so removing the router never affects it. Step by step.

I already use a gateway that falls back to another provider. Will switching still work?+

Partly. Router still moves a chat to another subscription before sending when an account’s usage shows it is spent. But a gateway that answers quota errors by switching provider hides those errors from Router, so it can’t fail a chat over mid-turn. An opt-in setting starts only Router’s engines on the built-in provider, without changing your Codex config or the official app.

Can I keep the official app open too?+

Yes. Router is a separate copy with its own profile, and it runs beside the official app. They share one chat store, so both list the same chats, but a chat runs on the engine of the app you send it from. Only Router’s window switches between subscriptions.
